# Building My Portfolio with Astro

I wanted to build a portfolio that was fast, simple,
and focused on content.

After exploring different options, I decided to use Astro
because it provides a lightweight approach for mostly
static websites while still allowing interactive components
when needed.

This is my first article written using Astro.
